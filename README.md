# World Cup LiveBoard 2026

A clean Vercel-ready Next.js starter for a premium World Cup live dashboard.

## Deploy
1. Upload these files to GitHub at the top level.
2. Import the repo into Vercel.
3. Click Deploy.

The top level of GitHub must show:
- package.json
- app/
- next.config.js
- postcss.config.js
- tailwind.config.js
- tsconfig.json
